For my experiments so far, I’ve observed the following:

### “Keep improving the result” approach:

This led to excessive blending and aggressive tuning of weighted sums. While it achieved an impressive CV score of 0.999, it ultimately suffered from severe data leakage, making the results unreliable.

### “Keep developing and extending the current best notebook with ~80% confidence toward a 0.938–0.94 LB” approach:

This strategy produced more reasonable and robust results, and importantly, the improvements translated well to the leaderboard (LB).

### Inverse submission guidance
“Which submission would most significantly change your strategy, confidence, or LB estimation?”

This approach is highly robust. Claude Code proposes a submission, and you intentionally use only a single submission to test that hypothesis. If the leaderboard (LB) result comes back negative, it provides a strong corrective signal—a high-value “reward” in terms of learning—because it prevents the agent from continuing to optimize in the wrong direction.

In other words, this method prioritizes information gain over incremental improvement, helping to realign strategy efficiently and avoid wasted iterations.

### Key takeaway:
The concept of an “imagination CV” does exist within LLMs. Even though constructing a reliable cross-validation scheme is particularly challenging in this competition, consistently reinforcing (rewarding) tools like Claude Code can lead the model to develop a perception-based proxy for CV.
While this is not a true statistical validation, it can still provide a useful directional signal for model improvement when conventional CV is difficult to implement.
